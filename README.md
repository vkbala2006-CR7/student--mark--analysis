# Student Mark Analysis

A data analysis and data cleaning project focused on processing student marks and academic records using Python.

## Project Structure
* `student data/` — Contains raw and cleaned student mark datasets (such as CSV files).
* `.github/` — Contains repository configurations and issue templates.

## Workflow Overview
1. **Load Data:** Import raw student marksheet CSV files into Python / Jupyter Notebook.
2. **Inspect & Clean:** Handle missing values, duplicate records, outliers, and formatting issues.
3. **Analyze & Export:** Perform mark/grade analysis and save the cleaned output (e.g., `student_marks_cleaned.csv`).
